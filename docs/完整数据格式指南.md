## 2. 核心概念

### 2.1 DVS (Dynamic Vision Sensor)

动态视觉传感器，输出**像素级亮度变化事件**

```
事件产生条件:
  ON事件:  I[t] > I[t-1] + threshold
  OFF事件: I[t] < I[t-1] - threshold

事件数据:
  (x, y, polarity, timestamp)
```

### 2.2 AER (Address Event Representation)

**地址事件表示** - 神经形态硬件标准通讯协议

```
原理:
  ├─ 每个事件表示为一个"地址"
  ├─ 地址编码 (x, y, polarity)
  ├─ 异步传输，低延迟
  └─ 与DVS芯片直接兼容
```

### 2.3 关键帧 vs 事件帧

- **关键帧 (Keyframe)**: 完整图像，用作参考
- **事件帧 (Event Frame)**: 仅变化事件

## 3. 完整数据格式

### 3.1 文件头 (.evs文件)

```
0        4        8
├─────────┼─────────┤
│ Magic # │ Version │
│ EVNT    │ 1       │
└─────────┴─────────┘
```

- **Magic Number**: `0x45564E54` (ASCII "EVNT")
- **Version**: `0x00000001`

### 3.2 数据包结构

每个数据包前有4字节长度:

```
[ Packet Length (4 bytes) ] [ Packet Content ]
```

### 3.3 关键帧数据包格式

```
0        4        8        12       16
├─────────┼─────────┼─────────┼─────────┤
│Frame #  │Type Flag│Timestamp│I-Frame  │
│         │  0x1    │         │Length   │
├─────────┴─────────┴─────────┴─────────┤
│           JPEG/H.264 Data             │
└───────────────────────────────────────┘
```

字段说明:

- **Type Flag**: `0x00000001` = 关键帧
- **Timestamp**: 毫秒，`0x00000000` = 未定义
- **I-Frame Data**: JPEG压缩的完整帧

### 3.4 事件帧数据包格式

```
0        4        8        12       16       20
├─────────┼─────────┼─────────┼─────────┼─────────┼─────────┤
│Frame #  │Type Flag│Timestamp│Regions  │DVS Evt  │AER Bytes│
│         │  0x0    │         │Count    │Count    │Count    │
├─────────┼─────────┼─────────┼─────────┼─────────┼─────────┤
│          Region Data (可选)         │
├─────────────────────────────────────┤
│          DVS Event List             │
├─────────────────────────────────────┤
│          AER Event Data             │
└─────────────────────────────────────┘
```

### 3.5 DVS事件编码 (12字节/事件)

```
0        2        4        5        8
├─────────┼─────────┼─────────┼─────────┤
│    X    │    Y    │Polarity │Reserved │
│  uint16 │  uint16 │ 0/1     │         │
└─────────┴─────────┴─────────┴─────────┘
```

### 3.6 AER事件编码 (8字节/事件 - 带时间戳)

```
0        4        8
├─────────┼─────────┤
│Address  │Timestamp│
│32 bits  │32 bits  │
└─────────┴─────────┘

Address字段位分配:
┌───────────────────────────────────────────┐
│Bit31 │Bits30-16│Bits15-0│
│Polarity│   X     │   Y    │
└─────────┴─────────┴─────────┘
```

## 4. AER集成详解

### 4.1 地址编码算法

```python
def encode_aer_address(x: int, y: int, polarity: int) -> int:
    """
    编码AER地址
    
    参数:
        x: 0-32767
        y: 0-65535
        polarity: 0 (OFF) 或 1 (ON)
    
    返回:
        32位地址
    """
    address = (
        ((polarity & 0x1) << 31) |
        ((x & 0x7FFF) << 16) |
        (y & 0xFFFF)
    )
    return address
```

### 4.2 地址解码算法

```python
def decode_aer_address(address: int) -> tuple:
    """
    解码AER地址
    
    返回:
        (x, y, polarity)
    """
    polarity = (address >> 31) & 0x1
    x = (address >> 16) & 0x7FFF
    y = address & 0xFFFF
    return x, y, polarity
```

### 4.3 与神经形态硬件连接

```
典型硬件架构:

  [DVS 像素阵列]
        ↓
  [仲裁器 (Arbiter)]  - 事件队列管理
        ↓
  [AER 编码器]        - 地址编码
        ↓
  [AER Bus]           - 40引脚并行总线:
                        ├─ 16位地址
                        ├─  Req (请求)
                        ├─  Ack (确认)
                        └─  握手协议
        ↓
  [接收设备]          - FPGA/神经形态芯片
```

### 4.4 AER总线协议

```
发送端:                    接收端:
   ┆                          ┆
   │  Req ← LOW               │
   │  地址 → 总线             │
   │  Req ← HIGH              │
   │                    Ack → LOW
   │  等待 Ack ← LOW          │
   │  Req ← LOW               │
   │                    Ack → HIGH
   ┆                          ┆
```

### 5.2 代码示例: AER集成

```python
from evs.event_detector import EventDetector
from evs.aer_encoder import AEREncoder
from evs.event_encoder import EventEncoder
from utils.io_utils import EventFileWriter

# 1. 初始化
detector = EventDetector(
    threshold=20.0,
    use_log_space=True,
    compare_with_previous=True
)
aer_encoder = AEREncoder(width=640, height=480)
event_encoder = EventEncoder(width=640, height=480)

# 2. 处理视频帧
for frame in video_frames:
    # 检测DVS事件
    events = detector.detect(frame)
    
    # 编码为AER格式
    aer_data = aer_encoder.encode_from_event_data(
        events, 
        include_timestamp=True
    )
    
    # 或: 完整EVS数据包
    packet = event_encoder.encode_events(
        events, 
        frame,
        include_aer=True
    )

# 3. 保存到文件
with EventFileWriter("output.evs") as writer:
    writer.write_packet(packet)
```

### 5.3 字节级数据示例

录制一段包含3个事件的事件帧:

```
数据包长度: 0x00000040 (64字节)

数据内容:
00000000: 0000 0001 0000 0000 0000 07D0 0000 0000   .....}...
00000010: 0000 0003 0000 0030 0064 0032 0100 0000   ...0.d.2....
00000020: 0064 0033 0000 0000 0064 0034 0100 0000   .d.3.....d.4...
00000030: 8064 0032 000F 4240 8064 0033 000F 424A   .d.2..B@.d.3..BJ
00000040: 8064 0034 000F 4254                           .d.4..BT
```

解析:

- `00000001`: 帧号 1
- `00000000`: 事件帧标志
- `000007D0`: 时间戳 2000ms
- `00000000`: 区域数 0
- `00000003`: DVS事件数 3
- `00000030`: AER数据 48字节
- 最后: 3个AER事件 (地址+时间戳)

## 6. 性能指标

### 6.1 数据量对比 (640x480, 30fps)

| 格式         | 数据量/秒      | 压缩比      |
| ---------- | ---------- | -------- |
| 原始RGB      | 27.6MB     | 1.0x     |
| H.264      | \~500KB    | 55x      |
| 事件型 (平均场景) | \~50-200KB | 140-550x |
| AER事件流     | \~30-150KB | 180-900x |

### 6.2 延迟

- 事件检测延迟: <1ms
- AER编码延迟: <0.1ms
- 端到端延迟: \~5-30ms (场景依赖)
